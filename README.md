# Cinematic Birthday Website — V2

This version follows the supplied exhibition/editorial reference more closely: large typography, lots of negative space, asymmetric composition, museum-style labels, floating visual objects, and a full-page layered lily background.

## Run
Open `index.html` or use VS Code Live Server.

## Assets
- Full background flower image: `assets/flowers/lilies-background.jpg`
- Reference screenshot: `assets/photos/reference-layout.jpg`
- Songs: put MP3s in `assets/music/`
- VN/video: put the file in `assets/videos/`

## Change songs
Edit the `tracks` array in `script.js`.

## Add real photos
Replace any `photo-placeholder` block in `index.html` with an image such as:
`<img src="assets/photos/photo01.jpg" alt="">`

The supplied lily image is already wired into the background, with several layered crops, a dark vignette, and grain so the whole page has the visual atmosphere rather than only a flower in one section.
